# Structure database for EXAFS fitting — core design

Status: implemented on `feat/structure-db` (2026-09-03), module
`crates/rexafs/src/xafs/structure/`. Larix parity target: CIF browser,
AMCSD database, Materials Project import → `feff.inp` → FEFF paths, with
path geometry available for a 3D visualiser.

## Pipeline

```
CIF file / AMCSD record / Materials Project doc
        │  cif::structure_from_cif · db::amcsd::AmcsdRecord::to_structure · db::mp::structure_from_doc
        ▼
   Structure  (lattice + fully expanded conventional cell + asymmetric unit + space-group info)
        │  cluster::build_cluster(&structure, &AbsorberSelection, &ClusterOptions)
        ▼
   Cluster    (absorber at origin, atoms sorted by distance, FEFF potentials, shells)
        │  feffinp::write_feff_inp(&cluster, &FeffInputOptions) → String
        ▼
   feff.inp   → xafs::fitting::runner::run_feff_and_load_paths (refeff / FEFF10 / FEFF8L)
        │
        ▼
   Vec<FeffPathModel>  — each FeffDat now carries `geometry_atoms: Vec<PathAtom>`
        │  paths::PathGeometry::from_feffdat · map_to_cluster(&cluster, 0.05)
        ▼
   PathGeometry (polyline through the cluster atoms) for the visualiser
```

## Data model (`model.rs`, `lattice.rs`, `element.rs`)

- `Lattice { a, b, c, alpha, beta, gamma, matrix }` — row vectors, `a` along
  x, `b` in xy; `to_cart` / `to_frac` / `volume` / `interplanar_spacing(i)`.
- `Species { symbol, occupancy, oxidation }`, `Site { label, species, frac,
  multiplicity, wyckoff, asym_index }`.
- `Structure { title, source, lattice, sites, asymmetric_sites,
  space_group: SpaceGroupInfo { number, hm_symbol, hall, operations },
  formula_sum, mineral, warnings }` with `formula()`, `elements()`,
  `composition()`, `sites_of(symbol)`, `equivalent_sites(i)`.
- `Element` table (Z = 1…103) generated from pymatgen: symbol, name, mass,
  covalent/atomic radius, Jmol CPK colour. `Element::from_label("Fe2+")`,
  `from_label("O1")`, `from_symbol`, `from_z`.
- Everything except `Element` is `serde` (de)serialisable so the GUI can
  persist a chosen structure/cluster in the project file.

## CIF and symmetry (`cif.rs`, `symmetry.rs`)

- Tokeniser handles `data_` blocks, `loop_`s, single/double quotes with the
  CIF closing rule, `;` text fields, `#` comments, `1.234(5)` uncertainties,
  `?`/`.` missing values. `parse_cif` → `Vec<CifBlock>`;
  `structure_from_cif` picks the first block with `_cell_length_a`.
- Sites from `_atom_site_{label,type_symbol,fract_x/y/z,occupancy,
  symmetry_multiplicity,wyckoff_symbol}`; element from the type symbol,
  else from the label. Sites at the same position merge into one
  mixed-occupancy site.
- Symmetry: explicit `_space_group_symop_operation_xyz` /
  `_symmetry_equiv_pos_as_xyz` loops win. Without them, the group is
  resolved from Hall symbol → H-M symbol (short, full, `P 1 21/c 1` style,
  `:H` suffixes) → IT number, using a bundled table of spglib's 530 Hall
  settings (`spacegroups.json.gz`, 20 KB, regenerated by
  `scripts/generate_spacegroup_table.py`). `expand_sites` applies the
  operations, wraps into [0,1), dedupes within 1e-3 and records
  multiplicity and `asym_index`.
- `structure_to_cif` writes the expanded cell as P1 (for the local library
  and for exporting database records).
- Parity: `tests/structure.rs` checks Ru hcp, RuO₂ rutile, FeS₂ pyrite and
  monoclinic ZrO₂ against pymatgen (three CIF variants each: with symops,
  without symops, P1) to 1e-4 in fractional coordinates.

## Cluster (`cluster.rs`)

- `AbsorberSelection::{SiteIndex(i), Element(symbol), ElementSite{symbol,
  nth}}`; `absorber_sites(structure, symbol)` lists one representative per
  crystallographically distinct site.
- `ClusterOptions { radius (8 Å), include_hydrogen (false), occupancy:
  Majority | Random{seed} }` — Larch/pymatgen conventions; majority
  species per mixed site with a warning listing what was dropped.
- Periodic images enumerated from the interplanar spacings; atoms sorted by
  distance, absorber first. Potentials: 0 = absorber, then one per species
  in order of first appearance by distance (every listed ipot is used).
- `Cluster::shells(tol)` groups neighbours by element and distance;
  `nearest(cart)` for mapping path legs.
- Parity: neighbour lists at 3 Å and 8 Å equal pymatgen's `get_neighbors`
  for all four fixtures; the ATOMS block matches pymatgen's `feff.inputs.
  Atoms` (ignored test, runs pymatgen through `uv`).

## feff.inp (`feffinp.rs`)

`FeffInputOptions { edge: Edge (K…M5), rmax, rpath, s02, scf, exafs, nleg,
style: Classic | Feff8, titles }`. `Classic` writes the `HOLE / CONTROL /
PRINT / RMAX / NLEG / EXAFS` cards the embedded ReFEFF and FEFF10 runners
already accept (verified: Ru hcp round-trips through `run_feff_and_load_paths`
with first-shell Reff 2.65/2.71 Å); `Feff8` writes Larch's `EDGE / S02 /
RPATH / (*)SCF / EXCHANGE` spelling. `Edge::default_for_z` = K below Ce, L3
above (Larch rule).

## Databases (`db.rs`, `db/amcsd.rs`, `db/mp.rs`)

- `trait StructureSource { name, search(&StructureQuery) -> Vec<StructureHit>,
  fetch(&StructureHit) -> Structure }`; `StructureQuery { text, elements,
  exclude, exact_elements, limit }` matches formula (composition-aware:
  `Ru O2` = `RuO2` = `O2Ru`), name, id and space group.
- `LocalCifLibrary::scan(dir)` indexes every `*.cif` recursively.
- `amcsd` (feature `amcsd`, `rusqlite` bundled): reads the SQLite layout of
  Larch/larixite (`amcsd_cif1.db` trimmed / `amcsd_cif2.db` full) — tables
  `cif`, `minerals`, `spacegroups` (H-M + JSON `x,y,z` operations),
  `cif_elements`; coordinates are base64 int32 × 4·10⁶ (`decode_farray`).
  Records are rebuilt into CIF text (`AmcsdRecord::to_cif`) and parsed
  with the same reader. `download_amcsd(dest, progress)` streams the full
  DB from the mirrors larixite uses (docs.xrayabsorption.org, figshare,
  millenia.cars.aps.anl.gov). A 5-record subset (`tests/testfiles/
  amcsd_subset.db`) covers tests; the trimmed 9 275-record DB ships with
  larixite in the test venv.
- `mp` (feature `materials-project`, `ureq` + rustls): v2 REST client,
  `materials/summary/?formula=…|chemsys=…|elements=…&_fields=…`, converts
  pymatgen `Structure` JSON (`lattice.matrix`, `sites[].species/abc`).
  `MaterialsProjectConfig { api_key, base_url, timeout_sec }`; the GUI
  owns the key. Fixture test + `#[ignore]` live test (`MP_API_KEY`).

## Path geometry (`paths.rs`)

`FeffDat.geometry_atoms: Vec<PathAtom { x, y, z, ipot, atomic_number,
label }>` is now filled from the `x y z ipot z label` lines of every path
file (additive, `#[serde(default)]`). `PathGeometry::from_feffdat` gives the
legs (absorber first), `polyline()` the closed loop, `half_length()` (=
Reff), `map_to_cluster(&cluster, tol)` the cluster atom index per leg and
`scatterers()` the atoms a path touches — what the 3D viewer needs to
highlight a selected path.

## What the GUI should call

1. Browse: `LocalCifLibrary::scan`, `Amcsd::open` (+ `download_amcsd`),
   `MaterialsProject::new(config)`; `search(query)` → hits; `fetch(hit)` →
   `Structure`. Or `read_cif(path)` for a dropped file.
2. Show the structure: `structure.sites` (frac → `lattice.to_cart`),
   `Element::from_symbol(sym).cpk`, `absorber_sites(&s, "Ru")` for the
   absorber picker, `equivalent_sites(i)`.
3. Cluster: `build_cluster(&s, &AbsorberSelection::…, &ClusterOptions { radius, .. })`
   → draw `cluster.atoms` (`cart`, `symbol`, `cpk`), `cluster.shells(0.01)`
   for the shell histogram, `cluster.warnings`.
4. FEFF: `write_feff_inp(&cluster, &FeffInputOptions { edge, .. })` into the
   workspace, run with the existing runner, then `PathGeometry::from_feffdat
   (&path.feff)` + `map_to_cluster` to draw paths.

## Left undone

- Wyckoff letters are not computed (only read when the CIF lists them).
- Hall-symbol parsing beyond the bundled table (non-standard settings not
  in spglib's 530) and magnetic groups are not supported.
- `OccupancyPolicy::Random` draws per atom rather than per site image; fine
  for FEFF clusters, not a substitute for a proper disorder model.
- AMCSD `download_amcsd` requires the `materials-project` feature for the
  HTTP client; COD and ICSD are not wired.
