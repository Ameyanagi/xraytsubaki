## Fit-space and multi-k-weight references

`fitspace_metadata.json` and `cu_fit_qspace.txt` are generated by
`crates/xraytsubaki/scripts/generate_larch_fitspace_references.py`
(`uv run --project crates/xraytsubaki/tests/pythonscript python <script>`),
using the same Cu data/path/parameters as the R-space reference above with an
explicit scalar `epsilon_k` (the `epsilon_k` recorded in `metadata.json`) so that
Larch does not estimate the noise itself. Cases:

- `cu_kspace_kw2`: `fitspace='k'`, `kw=2`
- `cu_qspace_kw2`: `fitspace='q'`, `kw=2` (`cu_fit_qspace.txt` holds `q`, data and model `chiq_re/chiq_im`)
- `cu_rspace_kw123`: `fitspace='r'`, `kweight=(1, 2, 3)`
- `cu_kspace_kw123`: `fitspace='k'`, `kweight=(1, 2, 3)`

`noise_estimate_kw123` records Larch's `estimate_noise()` output (`rmin=15`, `rmax=30`)
for `kweight=(1, 2, 3)`. Consumed by `tests/feff_larch_fitspace_parity.rs`.
